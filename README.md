# End-to-End Customer Analytics & Revenue Forecasting Using Python

## Project Overview

This project analyzes customer subscription data to understand customer behavior, revenue patterns, churn, subscription plans, marketing channels, and customer engagement.

The project follows an end-to-end Data Analytics workflow covering:

- Data cleaning
- Feature engineering
- Exploratory Data Analysis (EDA)
- Business analysis
- Data visualization
- Machine learning
- Model evaluation
- Feature importance
- Business recommendations

A Linear Regression model was developed to predict customer total revenue using customer and subscription-related features.

---

## Business Problem

Businesses need to understand customer behavior and revenue patterns to improve customer retention and revenue generation.

This project uses customer subscription data to answer questions such as:

- How does customer tenure relate to revenue?
- Which subscription plans generate higher revenue?
- How does churn vary across plans?
- Which marketing channels generate higher revenue?
- Which cities contribute higher customer revenue?
- Is customer engagement associated with revenue?
- Can customer characteristics be used to predict total revenue?

---

## Dataset

The dataset contains customer subscription information including:

- Customer ID
- Age
- Gender
- City
- Signup Date
- Last Active Date
- Plan Type
- Monthly Fee
- Tenure
- Support Tickets
- Average Session Time
- Discount Percentage
- Marketing Channel
- Churn Status
- Total Revenue

After duplicate removal, the analysis contains 2,500 customer records.
